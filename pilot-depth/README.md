# Soft depth pilot — 2026-11-19

سه طرح آزمایشی: کیف پول، سبد خرید، پشتیبانی. این پوشه نمونهٔ بازبینی است و جایگزین آیکون‌های فعلی نمی‌شود.

- منبع قابل ویرایش: `svg/`؛ هندسه در `scripts/generate-depth.mjs` تعریف می‌شود و آن اسکریپت SVG و کامپوننت را با هم بازتولید می‌کند. برای تغییر پایدار هندسه، همان اسکریپت را ویرایش کنید.
- چهار اندازهٔ واقعی: 16، 20، 24، 32؛ گرید 24 و stroke 1.75 حفظ شده‌اند.
- سطح جلویی 9٪ و سطح پشتی 28٪ از `currentColor`؛ جزئیات 18٪؛ خط اصلی رنگ کامل دارد.
- حجم UI از دو سطح ساخته شده؛ بدون فیلتر، گرادیان یا شناسهٔ مشترک در خود SVG. سایهٔ نمای بزرگ فقط در صفحهٔ پیش‌نمایش است.
- زاویهٔ مورب و حرکت V از لوگوی موجود الهام گرفته شده؛ تناسبات این پایلوت پیشنهاد طراحی‌اند، نه اندازه‌برداری دقیق از لوگو.
- نسخهٔ تصویری سه‌بعدی، اتود هنری جداست؛ برای آیکون 24 پیکسل از فایل React/SVG استفاده کنید.

```tsx
import { WalletDepth, ShoppingCartDepth, HeadphonesDepth } from '@vserv/icons/depth';
<button aria-label="کیف پول"><WalletDepth size={24} /></button>
<HeadphonesDepth title="پشتیبانی" size={32} style={{color:'#8bdcff'}} />
```

`npm run build` همهٔ نمونه‌ها را تولید می‌کند. صفحهٔ `preview/index.html` را مستقیم باز کنید. فعلاً تنها همین سه نمونه اضافه شده‌اند؛ بقیهٔ خانواده و پروژه‌های مصرف‌کننده تغییری نکرده‌اند. بیلد، نام دسترس‌پذیر، SVG و tree-shaking بررسی شده‌اند؛ تست مرورگری همچنان نیازمند محیط قابل اجرای Chromium است.
